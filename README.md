# FormsADDA CAT QA & VARC Guess Paper 2027

Official landing page for the **CAT Quantitative Ability & VARC Guess Paper 2027** by FormsADDA.

## Product

- **Exam:** CAT 2027
- **Sections:** Quantitative Ability (QA) + Verbal Ability & Reading Comprehension (VARC)
- **Price:** ₹99 (original ₹299)
- **Format:** Digital PDF — Instant Access
- **Checkout:** https://formsadda.com/guess-paper/management/cat

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS v4
- FontAwesome 6 (CDN)
- Google Fonts (Inter, Outfit, DM Sans)

## Development

```bash
npm install
npm run dev       # Start local dev server at http://localhost:5173
npm run build     # Production build
npm run preview   # Preview production build locally
```

## Project Structure

```
src/

  index.css       # Global styles (FormsADDA design system)
```
